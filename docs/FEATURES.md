# ฟีเจอร์และการทำงานของระบบ

## ผู้อ่าน
- ชั้นหนังสือ ปกเรื่อง (อัปโหลดเองหรือสร้างอัตโนมัติ) สารบัญ ตัวละครของเรื่อง
- หน้าอ่านปรับธีม/ฟอนต์/ขนาดตัวอักษร/ความกว้าง/ระยะบรรทัดได้ เลือกตอนจากในหน้าอ่านได้ ซ่อนแถบบนตอนเลื่อน ปัดซ้าย/ขวาเปลี่ยนตอนบนมือถือ ฟอนต์อยู่ในตัวเว็บ (ไม่เรียก Google Fonts)
- ฟังเสียงอ่านภาษาไทย (ใช้เสียงของเบราว์เซอร์ ต้องมีเสียงไทยในเครื่อง)
- ดาวน์โหลดทั้งเรื่องเป็น EPUB (เฉพาะตอนที่เผยแพร่) ติดตามตอนใหม่ผ่าน RSS (ปุ่ม RSS ที่หน้าเรื่องคัดลอกลิงก์ feed)
- หน้าแรกค้นหา/เรียงลำดับ/กรองตามแนวได้ (แนวใส่ได้หลายค่าคั่นด้วย `,` เช่น `Isekai, Slice of Life` ปุ่มกรองแยกเป็นแท็กต่อแท็ก ไม่สนตัวพิมพ์เล็กใหญ่) มีป้าย "จบแล้ว" / "อัปเดตใหม่"
- ถ้าล็อกอิน: จำตำแหน่งที่อ่านค้าง ตอนที่อ่านแล้ว และการตั้งค่าอ่าน (ธีม/ฟอนต์/ขนาด/ความกว้าง/ระยะบรรทัด ที่ `users.prefs`) ข้ามอุปกรณ์ ล็อกอินเครื่องใหม่แล้วใช้ค่าของบัญชี ถ้าบัญชียังไม่เคยบันทึกจะอัปโหลดค่าของเครื่องนี้ มี "ชั้นหนังสือของฉัน" (ปุ่มติดตามเรื่อง)
- `/following` (เมนู "บัญชี"): เรื่องที่ติดตามพร้อมความคืบหน้า (อ่านแล้วกี่ตอน ค้างกี่ตอน ปุ่มอ่านต่อ) กรอง/เรียงได้ เลิกติดตามทีละเรื่องหรือหลายเรื่องพร้อมกันได้

## บัญชีและอีเมล
- สมัครสมาชิกแล้วต้องยืนยันอีเมลด้วยรหัส 6 หลัก (ใช้ได้ 10 นาที ผิดได้ 5 ครั้ง ขอใหม่ได้นาทีละครั้ง) จึงจะเข้าสู่ระบบได้ ถ้ารหัสผ่านถูกแต่ยังไม่ยืนยัน ระบบส่งรหัสใหม่และพาไปหน้ากรอกรหัส
- ลืมรหัสผ่าน (`/forgot`): กรอกอีเมล รับรหัส ตั้งรหัสผ่านใหม่ ไม่บอกว่าอีเมลนั้นมีบัญชีหรือไม่
- ตั้งรหัสผ่านใหม่ (ลืมรหัสผ่านหรือเปลี่ยนที่ `/profile`) ทำให้อุปกรณ์อื่นที่ล็อกอินค้างอยู่หลุดทันที (เครื่องที่เปลี่ยนรหัสเองยังอยู่) เก็บเวลาที่ `users.password_changed_at` และปฏิเสธโทเคนที่ออกก่อนเวลานั้น
- เปลี่ยนอีเมล (`/profile`): ใส่อีเมลใหม่กับรหัสผ่านปัจจุบัน รหัสไปที่อีเมลใหม่ อีเมลเปลี่ยนเมื่อกรอกรหัสแล้วเท่านั้น
- ลบบัญชีเอง (`/profile`): ยืนยันด้วยรหัสผ่าน + รหัส 6 หลักทางอีเมล ลบถาวร (ความคิดเห็น รีวิว โหวต ที่ติดตาม แจ้งเตือนหายไปด้วย) นักเขียนที่ยังมีเรื่องต้องลบเรื่องก่อน และบัญชี admin ลบเองไม่ได้
- อีเมลที่ส่งออกใช้หน้าตาตามธีมเว็บ (มีโหมดมืด) ตัวสร้างอยู่ที่ `server/src/mail.ts` รหัสเก็บเป็น HMAC ในตาราง `email_codes` ไม่เก็บรหัสจริง
- สมาชิกที่มีอยู่ก่อนเปิดระบบนี้ถือว่ายืนยันแล้ว (migration 0015)

## ผู้ดูแล (admin)
- สร้างเรื่อง ให้ AI เขียนตอนใหม่แบบเห็นข้อความไหลสด
- ตัวแก้ไขตอนแบบ WYSIWYG (แทรกรูป ปรับขนาด/จัดวาง/คำบรรยาย) สรุปตอนอัตโนมัติ
- จัดการตัวละคร (ให้ AI เสนอจากเรื่องได้)
- เผยแพร่/ซ่อนตอน ตั้งเวลาเผยแพร่ ประวัติเวอร์ชันของตอน (กู้คืนฉบับก่อนแก้/ก่อนเขียนใหม่ได้)
- แผนเรื่อง (ให้ AI เขียนตามแผนทีละตอนหรือหลายตอนติดกัน) ปุ่มตรวจความต่อเนื่อง
- ดูค่าใช้จ่าย (tokens / USD) ต่อตอนและทั้งเรื่อง สถิติการอ่านต่อตอน (ดู "ข้อควรรู้" ใน README) ค้นหานิยายตามชื่อ จัดการผู้ใช้

## นักเขียน (writer)
- admin เป็นคนให้สิทธิ์เท่านั้น (หน้า "ผู้ใช้") เขียนและจัดการได้เฉพาะเรื่องที่ตัวเองสร้าง ดูผู้ใช้/งบรวมไม่ได้
- การเปลี่ยนสิทธิ์ทุกครั้งบันทึกในตาราง `audit_log` และแสดงในหน้าเดียวกัน
- ทุกคนแก้ชื่อ/แนะนำตัว/รหัสผ่าน/อีเมลที่ `/profile` หน้าผู้แต่งอยู่ที่ `/author/:id`

## ชุมชนผู้อ่าน
ทุกคนอ่านได้ ต้องล็อกอินถึงเขียนได้

- **รีวิว** (หน้าสารบัญ): 1–5 ดาว + ข้อความไม่บังคับ คนละ 1 รีวิวต่อเรื่อง แก้ไขได้ ผู้แต่งรีวิวเรื่องตัวเองไม่ได้ ลบได้เฉพาะเจ้าของรีวิวกับ admin
- **คะแนน**: แสดง "★ 4.3 (12)" ใต้ปกที่หน้าแรกและหน้าผู้แต่ง เรียง "คะแนน" ได้ (ถ่วงค่าเฉลี่ยกับจำนวนรีวิว เรื่องที่มีรีวิวเดียว 5 ดาวจึงไม่ชนะเรื่องที่มีรีวิวดีหลายสิบ) หน้าสารบัญแสดงจำนวนคอมเมนต์ข้างแต่ละตอน
- **คอมเมนต์** (หน้าอ่านแต่ละตอน พับไว้เป็นค่าเริ่มต้น): ตอบกลับได้ลึก 1 ชั้น โหวตขึ้น/ลงได้ (โหวตของตัวเองไม่ได้) เรียงตาม ใหม่ล่าสุด (ค่าเริ่มต้น) / ยอดนิยม / ตอบกลับมากสุด
- เจ้าของแก้คอมเมนต์ตัวเองได้ (ขึ้น "แก้ไขแล้ว") ลบได้โดยเจ้าของ ผู้แต่งเรื่อง และ admin (ลบคอมเมนต์หลักจะลบการตอบกลับใต้มันด้วย)
- **รายงาน**: ทุกคนรายงานคอมเมนต์ของคนอื่นได้ admin ดู/ปิดรายงานหรือลบที่ `/admin/reports` (ป้ายตัวเลขที่แท็บ "รายงาน") การลบโดย admin หรือผู้แต่งบันทึกใน `audit_log`

## แจ้งเตือน (กระดิ่งบนหัวเว็บ)
บอกเมื่อ (1) เรื่องที่ติดตามมีตอนใหม่ที่ยังไม่ได้อ่าน (2) มีคนตอบกลับคอมเมนต์ของคุณ (3) คอมเมนต์ของคุณได้โหวตขึ้น (โหวตลงไม่แจ้ง และไม่บอกว่าใครโหวต)

- ตอนใหม่นับจาก `chapters.released_at` (เวลาที่ตอนขึ้นให้ผู้อ่านเห็นจริง ไม่ใช่ `created_at`): ตอนที่ตั้งเวลาไว้จะแจ้งตอนเวลามาถึง และฉบับร่างเก่าที่เพิ่งกดเผยแพร่ก็นับเป็นตอนใหม่
- รายการตอนใหม่คำนวณสด ไม่เก็บเป็นแถว จึงไม่ต้องมีตัวตั้งเวลา และหายไปเองเมื่ออ่านตอนนั้นแล้ว
- ตัวเลขบนกระดิ่งอัปเดตทุก 1 นาที

## หน้าแรกและโครงเส้นทาง
- `/` หน้า landing (แนะนำเว็บ ปกนิยายแนะนำ แถวอัปเดตล่าสุดกับคะแนนสูงสุดจากเรื่องจริง ขั้นตอนที่นิยายเกิดขึ้น เชิญนักเขียน)
- `/story` ชั้นนิยายทั้งหมด (ค้นหา/กรอง/เรียง) และ `/story/:id` หน้าเรื่อง
- ผู้ใช้ที่ล็อกอินอยู่แล้วเปิดเว็บใหม่จะเข้า `/story` ตรง ๆ (กดโลโก้ภายในเว็บยังเห็น landing)

## หน้าข้อกำหนดและข้อมูลของเว็บ
`/guide` คู่มือ, `/about` เกี่ยวกับเรา, `/contact` ติดต่อเรา, `/terms` ข้อกำหนด, `/privacy` นโยบายความเป็นส่วนตัว (ลิงก์ที่ท้ายเว็บ)

- ข้อความตั้งต้นอยู่ใน `server/src/pageDefaults.ts` (Markdown เขียนจากสิ่งที่ระบบทำจริง ถ้าเปลี่ยนพฤติกรรมของระบบ ต้องแก้ข้อความเหล่านี้ด้วยและแก้ `DEFAULTS_UPDATED`)
- admin แก้แต่ละหน้าที่ `/admin/site` (เมนู "เว็บไซต์") ด้วย TipTap แบบ WYSIWYG (หัวข้อ ตัวหนา รายการ ลิงก์ โค้ด ไม่มีรูป) และแท็บ Markdown สำหรับข้อความดิบ มีตัวอย่างก่อนบันทึก ประวัติทุกเวอร์ชัน และปุ่มกลับไปใช้ข้อความตั้งต้น วันที่ "ปรับปรุงล่าสุด" เปลี่ยนเองเมื่อบันทึก
- ในข้อความใช้ `{{operator}}` และ `{{contactEmail}}` แทนชื่อผู้ให้บริการและอีเมลติดต่อ ซึ่ง admin ตั้งที่หน้าเดียวกัน (ไม่ตั้งก็ใช้ `OPERATOR_NAME` / `CONTACT_EMAIL` ใน `server/.env` แล้วค่าเริ่มต้น)
- สมัครสมาชิกต้องติ๊กยอมรับข้อกำหนดและนโยบาย API บังคับด้วย (`acceptTerms`) เก็บเวลาที่ `users.terms_accepted_at` การแก้ข้อความไม่ทำให้ผู้ใช้เดิมต้องยอมรับใหม่

## ใครจ่ายค่า AI

เว็บนี้**ไม่มีคีย์ OpenRouter กลาง** ทุกคนที่ใช้ AI (นักเขียนและ admin ไม่มียกเว้น) ใช้คีย์ของตัวเอง ตั้งที่ "โปรไฟล์ของฉัน"

- ระบบตรวจกับ OpenRouter ก่อนบันทึก เก็บเข้ารหัส AES-256-GCM ในตาราง `user_ai_keys` โดยผูกกับ user id (คัดลอกข้อมูลเข้ารหัสไปแถวของคนอื่นแล้วถอดรหัสไม่ได้)
- ไม่ส่งกลับไปที่หน้าเว็บ (เห็นแค่ 4 ตัวท้าย) และอยู่จนกว่าจะลบเอง ไม่หมดอายุตามการล็อกอิน (ล็อกอินอยู่ 30 วันนับจากวันที่ล็อกอิน ไม่ต่ออายุเมื่อใช้งาน)
- ลดสิทธิ์นักเขียนเป็นผู้อ่านจะลบคีย์ให้
- ผู้ที่ยังไม่ตั้งคีย์ใช้ปุ่ม AI ไม่ได้ (นักเขียนเขียนเองได้) มีแต่ admin ที่ใช้โมเดล `local:` ได้โดยไม่ต้องมีคีย์
- ตั้ง `KEY_ENCRYPTION_SECRET` ใน `server/.env` (ไม่ตั้งจะใช้ `JWT_SECRET`) **ถ้าเปลี่ยนค่านี้ คีย์ที่เก็บไว้จะอ่านไม่ได้ ทุกคนต้องกรอกใหม่**
- ทุกการเรียกโมเดลบันทึกลงตาราง `ai_usage` พร้อมคนที่จ่าย (ไว้ดูภายหลัง ไม่มีเพดานงบกลางแล้ว)
